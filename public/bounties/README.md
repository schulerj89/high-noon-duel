# Bounty Portraits

These portraits are generated bitmap assets for the bounty board. They are intentionally image-only portraits; poster text such as WANTED, enemy name, reward, difficulty, and description is rendered by the game UI from `src/data/enemies.ts`.

Current files:

- `billy-the-shaky.webp`
- `red-eye-ramos.webp`
- `marshal-graves.webp`
- `dust-widow.webp`
- `the-black-hat.webp`

The source prompts asked for low-poly western wanted-poster portrait art with no text, labels, watermark, UI frame, or full poster copy.
